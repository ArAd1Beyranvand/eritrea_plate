# eritrea_plate

Eritrea's licence plates for the plate_core library — categories, colours, themes, alphabets and an advisory validator.

## Quick start

### Install (TypeScript)

Copy `typescript/src/countries/eritrea/` into `plate_core/typescript/src/countries/`.

Then run the tests from `plate_core/typescript/`: `npm test`.

### Use

```ts
import country from './countries/eritrea';

const spec = country.specs.get('er.standard');
console.log(country.package);
```

## Specs

The specs are the same in every language (they come from shared data).

- `er.standard`

## Themes

- `EritreaThemes.standard`

## Change it

- Specs: `country.specs`, by id.
- Themes: `country.themes`.
- Validators: `country.validators` (`EritreaValidator`).
