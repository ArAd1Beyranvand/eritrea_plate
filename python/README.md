## Quick start

### Install (Python)

Copy `python/plates/countries/eritrea/` into `plate_core/python/plates/countries/`.

Then run the tests from `plate_core/python/`: `pytest`.

### Use

```python
from plates.countries.eritrea.data import SPECS, THEMES

spec = SPECS["er.standard"]
theme = THEMES["EritreaThemes.standard"]
print(spec.id)
```

## Specs

The specs are the same in every language (they come from shared data).

- `er.standard`

## Themes

- `EritreaThemes.standard`

## Change it

- Pick a spec: use another key of `SPECS`.
- Pick a theme: use another key of `THEMES`.
- Validators: `VALIDATORS` maps the names `EritreaValidator` to classes.
